Instances, as in Figma

An instance overrides its parts, fills its slots and finds its main

Each example below is an instance. Its parts take style overrides written on the instance, which win over the main and its options. A slot the main marks takes the instance's own layers. A component still kept as a file in components/ moves onto the canvas as a main.

  1. Double-click the Alert, then click its heading. The header reads "Part of Alert, overridden.": the accent colour comes from zd-style-alert-heading on this instance only. Click Reset under the header, then Undo.
  2. With that heading selected, change its size in the Style panel. The change lands in the same attribute, and the Alert main on page 3 keeps its look. Its text still changes only through the instance's Options.
  3. Select the Empty panel and draw a Text layer inside its body. The layer joins the Body slot. Select the panel again: Options shows Body with 1 layer and Reset to default.
  4. Select the Card. It comes from components/card.html, so the header offers Move main to canvas. Click it: the card becomes a main frame on this page in one undo step, and the header then reads Edit main. Undo afterwards, so components/card.html stays for page 4.
