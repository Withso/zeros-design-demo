Template issues

This frame is a component with two options, Tone and Show the wrapped card. Each half shows a problem in how Zeros handles a component's template.

  1. Select the frame and change Tone in Options. The badge follows, because the hole fills its class.
  2. Ask the agent to validate this frame. It still warns that pieces of the class attribute are unknown classes.
  3. Turn Show the wrapped card off and on. Its text comes and goes, but it never becomes a card.

1 · A hole in a class attribute

It renders right. Validate checks the attribute as written and splits it at the spaces inside the hole, so each piece warns. Page 3's Badge draws one copy per look with data-zd-if to avoid this.
