More styles: every other declaration

More styles lists each authored declaration that no other section shows, as a name and a value written as text. You can add any property the browser knows by name. With the frame selected, Export at the end of the panel saves a PNG.

  1. Select "Cursor and selection": More styles lists cursor and user-select with their values as written.
  2. Type a new property at the end of More styles. zIndex is written as z-index.
  3. Click the frame title and scroll to Export: pick 1x, 2x or 3x and press Export PNG.
