Zeros Design demo

Orbit: a tour of the Design tab

Each page shows one part of the Design tab, using a small made-up design system called Orbit. Frames are plain HTML and CSS files in this folder. Every edit you make is saved straight into those files, so the Changes view shows exactly what it wrote.

The pages, in order

How to move around, and where each kind of edit is saved. tokens.css: colours, type styles, spacing and the Light and Dark themes. Ten components covering every option kind, derived values, loops and conditions. components/*.html files filled with children and attributes. Every Button combination, variants, overrides and instances in context. Hover, focus, pressed and disabled: live rules and drawn states. One frame per section: position, layout, fill, type, stroke, effects, motion. Field marks, where values come from, and where edits are written. CSS, Sass, Tailwind and build sources declared in canvas.json. What the authoring checks warn about, on purpose. Eleven problems this demo ran into, with a frame for each one the canvas can show. The tour as text. README.md covers opening the demo and the checks.

On every page

Frames are HTML files. Select one, or a layer inside it, to edit it in the Style panel.

Notes beside each frame say what it shows, what to try, and what an edit writes.

Link cards open the matching guide in docs/ or a source file in Files.
