Lint showcase

What Zeros checks, and where you see it

Zeros checks each frame's source whenever it changes. An error makes Validate fail and puts a red line at the top of the Style panel. A warning never fails Validate and never blocks a save. The canvas does not list warnings: the agent's Validate step reports them, each with its file, line and a fix.

  1. In the chat, ask: Validate every frame on the Lint showcase page. Each other frame on this page breaks one rule on purpose, and its note quotes what Validate reports.
  2. Ask the same for page 2. Pages 1 to 9 report nothing, because they follow the rules in rules.md.
  3. Ask the agent to fix the Unknown classes frame, then open Changes to see its edit. Discard the change to put the demo back.

Errors: Validate fails

RuleWhat breaks it
frames-are-valid-htmlHTML the parser has to repair, such as a stray end tag
no-scriptA script element: frames are HTML and CSS only
no-event-handlersAn attribute such as onclick
no-external-urlA stylesheet, image or link from another site
local-refs-onlyA path that leads outside the Design folder
component-undefinedA zd- tag that no component answers to
component-invalidA broken component file, or one name registered twice
component-value-invalidAn instance value its option does not allow, such as an unlisted choice
component-expression-invalidA template expression that cannot be worked out

Warnings: advisory

RuleWhat breaks it
unknown-tokenA var() of a token nothing declares, with no fallback
literal-token-valueA hex, rgb() or hsl() colour equal to a token's value
unknown-classA class with no CSS in the frame's styles
repeated-inline-styleThe same two or more inline declarations on three layers
repeated-markupThe same tree of tags and classes, three times
oid-duplicateTwo layers with one data-oid
component-value-invalidAn instance attribute that names no option; Zeros ignores it
component-option-invalidA second options template, or one outside head
component-unregisteredOptions in a frame that has no component name
canvas-item-link-missingA link card whose file is gone

Style panel

A red line names the first error in the folder as file:line and rule. Hover it for the message.

Options

When an instance's values cannot apply, Options says what the frame shows instead and offers Ask agent to fix. An ignored attribute gets a warning there.

Validate

The agent runs design validate on a frame and gets every error and warning, each with a fix. Warnings leave its exit status at 0.
