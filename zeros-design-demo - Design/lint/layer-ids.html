Duplicate layer ids

Rule 5 in rules.md: data-oid is optional, but each one must be unique in its frame. It is how Zeros finds a layer again after the markup around it changes. Validate warns when two layers share one.

  1. Ask the agent to validate this frame: data-oid "li-save" is duplicated in this frame.
  2. Select each button on the left in turn and watch the Style panel header and Layers.
  3. Give the second button its own id in Files, for example li-save-copy, or ask the agent. The warning goes away.

Warns: one data-oid on two layers

Fixed: one data-oid each

Every other frame in this demo has a data-oid on each layer already. Most layers here have none, on purpose: a Style edit writes one only on the layer you edit, so Changes shows just that layer's line.
