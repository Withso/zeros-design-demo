A build command, run live

Some styles only exist after a build. This source names the command and its output. While Design is open, Zeros runs it in the repository and runs it again when its inputs change; frames read the CSS it writes.

  1. Open the theme editor (⌥T) and choose Token build. The status reads "Live: Zeros runs … when styles/build change, while Design is open".
  2. Change "accent" in styles/build/tokens.json and save. The build runs again and this card redraws with the new colour.
  3. Select the card. Its values come from the class .ds-surface, Source Token build, and read the --ds-* variables the script writes.

The declaration in meta/canvas.json

{ "id": "tokens-build", "kind": "build",
  "path": ".zeros/design-styles/tokens.css",
  "command": "node styles/build/build-tokens.mjs",
  "inputs": ["styles/build"], "timeoutSeconds": 30,
  "themes": { "dark": "[data-theme=\"dark\"]" } }

The command runs with /bin/sh in the repository root. ZEROS_DESIGN_STYLE_OUTPUT names the file to write. The output sits in .zeros/design-styles, which Git ignores, so builds never show up in Changes.

Repository builds run by default. To stop them on this machine, set design.repository_style_builds to false in your settings; your own [[design.style_builds]] entry for the same output replaces this command.
