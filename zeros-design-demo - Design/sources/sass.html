Sass, compiled by Zeros

styles/sass/app.scss uses two partials, nesting, a mixin and an @each loop. Zeros compiles it with its own Dart Sass and imports the CSS. Nothing in the repository runs, and no install is needed.

  1. Open the theme editor (⌥T) and choose Sass app: "Compiled with Sass", then the --sass-* variables, each with a Dark value.
  2. Select a tile. Styled by lists .tile; Fill reads sass-surface, From the class .tile, Source Sass app.
  3. Preview Dark: pick Dark in the menu beside Search. The Sass entry's prefers-color-scheme block is mapped to the Dark theme.
  4. Edit styles/sass/_tokens.scss and save. The source recompiles and the frame redraws; no button needed.

Nesting and BEM

In app.scss, the &__title, &__meta, &--featured and &:hover blocks inside .tile compile to .tile__title, .tile__meta, .tile--featured and .tile:hover.

@each and @include

One @each over the tones writes .tag--teal, .tag--amber, .tag--rose and .tag--violet. The pill mixin gives each one the same shape.

Sass maps to CSS variables

_tokens.scss holds two Sass maps. The entry writes them out as --sass-* variables, which the theme editor lists and the token picker offers in this frame.
