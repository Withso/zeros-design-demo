Status, problems and which frames get what

Every declared source has a status in the theme editor: Ready, Warning or Error, with messages that say why. Two sources here are broken on purpose, so you can see both.

  1. Open the theme editor (⌥T). Legacy vendor CSS shows Warning with two messages; Removed stylesheet shows Error and Not imported. Each offers Ask agent to fix.
  2. Open Styles only in the Sources list: Brand motion and Legacy vendor CSS have rules but no variables.
  3. Press Update sources (the circular arrow) to re-read every source now. Saving a source file does the same on its own.

Which frames get which sources

A frame with a styles list in meta/canvas.json gets only those sources. A frame with no list gets every source. Pages 1 to 8 list none, so they use only tokens.css and the stylesheets they link.
